## 📋 Что делает парсер

### Основной функционал
1. **BFS-обход категории** [`Фильмы по алфавиту`](https://ru.wikipedia.org/wiki/Категория:Фильмы_по_алфавиту)
2. **Сбор данных** с каждой страницы фильма:
   - Название
   - Год выпуска
   - Жанр
   - Режиссёр
   - Страна
   - Ссылка на Википедию

### Интеграция с IMDb
- Автоматический поиск ссылки на IMDb на странице Википедии
- Парсинг актуального рейтинга с IMDb (с обходом защиты через User-Agent)
- Объединение данных из двух источников в одну запись

## 🛠 Установка

**Требования:** Python 3.8+

# Установка и запуск movie_parser_scrapy

## 1. Клонирование репозитория
```bash
git clone https://github.com/nikitruhin/movie_parser_scrapy.git
```

## 2. Переход в папку с run.py
```bash
cd movie_parser_scrapy/Desktop/movie_parser_scrapy/movie_parser_scrapy
```

## 3. Установка зависимостей
```bash
pip install scrapy requests
```

## 4. Запуск run.py
```bash
python run.py
```
Готово! Результаты сохранятся в CSV-файле.
